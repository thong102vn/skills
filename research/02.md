# phase 2:
Re-evaluate current backlogs against all real world needs/demands (Vietnam market first using domain's own language) from personal to SME to enumerate all current limitations and gaps. Decompose exhaustively to not miss epics, features with implementation-ready user stories and decision bound for reusing or reference to opensources and do not miss wireframes with best UX design for production-grade. Don't create duplicate file/content. Coverage-Driven Decomposition (CDD)
  0. (NEW) Discover and critique the axes themselves, not just their values. Apply open-discovery recursively: axes → values
  → cells. Ask "what dimensions does variation live along in this domain?" (add temporal/legal-state, jurisdiction-tier,
  data-availability if they exist) and let an independent lens challenge the axis set before you build the matrix.

  1. Open-discovery on every axis's values, with a saturation test — not just the dominant ones. Stop enumerating an axis
  only when a fresh source adds nothing new (second-source-dry), so completeness is tested, not assumed.

  2. Cross the 2–3 highest-variance axes into the matrix — but NO axis is silently excluded. Every un-crossed axis becomes a
  mandatory overlay sweep against the full epic set (I did this for obligation + non-happy-path; the fix is to make it
  mandatory for actor×lifecycle, channel, jurisdiction, scale too). An axis is either a matrix dimension or an explicit
  sweep — never dropped.

  3. Every cell carries evidence + confidence + a pointer to the covering epic/feature. "✓ covered" without a specific
  feature-ID is a claim to be verified, not a fact — kill hand-wavy green (some of my "✓"s were vibes, which the critic is
  now catching). Empty cells get a severity (impact × frequency) so deferrals are principled, not arbitrary.

  4. Reuse/build per cell — unchanged, but the OSS check runs when the cell is created, not bolted on later (my E-VN-19/20
  skipped it and I shipped a wrong OSS note).

  5. Independent, multi-lens, looped critic that attacks three things, not one. (a) Multiple diverse lenses (per-persona,
  per-jurisdiction, adversarial-fraud), not a single self-administered pass; (b) it attacks omissions AND weak-coverage AND
  wrong-dispositions, not just empty cells; (c) loop-until-dry with a real criterion (K consecutive passes find nothing),
  and critic findings loop back to re-run discovery on the axis that leaked. Stop only at double-saturation — discovery and
  critic both dry.

  6. "Coverage & known-gaps" with re-entry triggers. Every "deferred Y" gets a condition/date that pulls it back — otherwise
  "deferred" is just "silently dropped with extra steps." Phrase as "covered X (evidence), deferred Y (until trigger Z)."

  + Depth dial (cross-cutting): scale discovery breadth, matrix dimensionality, and critic-lens count to the stakes — a
  one-off feature doesn't need this; a whole-market backlog does.
